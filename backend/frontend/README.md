# Altis Voyage frontend

The frontend is a React/Vite application with PWA support through `vite-plugin-pwa`.

Use the repository-level [README](../README.md) for:

- local development
- LAN development and preview
- frontend and backend environment variables
- PWA builds and installation notes
- admin image management
- Render deployment

Frontend commands:

```powershell
npm ci
npm run dev
npm run lint
npm run build
npm run preview -- --host 0.0.0.0
```
